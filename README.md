# CodeAlpha_Calculator

Task 2 of the CodeAlpha Frontend Development internship: a calculator built with HTML, CSS and JavaScript.

## Features
- Addition, subtraction, multiplication and division
- Chained calculations (2 + 3 × 4 is evaluated left to right, like a pocket calculator)
- AC, backspace, percent, plus/minus and decimal point
- Real-time display with a small line showing the current expression
- Divide-by-zero and overflow messages, and no floating point noise (0.1 + 0.2 = 0.3)
- Bonus: full keyboard support, calculation history (click an entry to reuse the result)

## Keyboard
`0-9` digits, `.` decimal, `+ - * /` operators, `Enter` or `=` equals, `Backspace` delete, `Esc` clear, `%` percent.

## Run it
Open `index.html` in a browser. No build step needed.
